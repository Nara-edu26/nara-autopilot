# Musik reel (opsional)

Taruh 5–10 file `.mp3` atau `.m4a` bebas royalti di folder ini, lalu commit. Renderer memilih satu lagu per reel secara otomatis (selalu lagu yang sama untuk post yang sama).

Syarat: lisensinya harus mengizinkan dipakai di media sosial tanpa atribusi, misalnya musik dari YouTube Audio Library yang berlabel "no attribution required". Simpan bukti lisensinya.

Tanpa file di sini, reel tetap jadi dengan trek audio senyap.
