# Musik reel

Empat trek di folder ini (`nara-*.m4a`, ±48 detik, 76–92 bpm) adalah musik original yang dibuat dengan kode
oleh Claude pada 2 Nov 2026 (akor, petikan, bass, dan ketukan lembut yang disintesis dari gelombang sinus).
Tidak memakai sampel atau rekaman pihak lain, jadi tidak ada lisensi atau atribusi yang perlu diurus.

Renderer memilih satu lagu per reel secara otomatis (selalu lagu yang sama untuk post yang sama) dan
mengulangnya bila reel lebih panjang. Saat suara Nara aktif, volume musik dikecilkan ke 0,14.

Boleh menambah file `.mp3`/`.m4a` lain asal lisensinya mengizinkan dipakai di media sosial tanpa atribusi
(misalnya YouTube Audio Library berlabel "no attribution required"). Simpan bukti lisensinya.
